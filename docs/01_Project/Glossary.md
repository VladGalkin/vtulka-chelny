# Глоссарий

**B2B** — взаимодействие компаний / профессиональных покупателей друг с другом.

**Каталог** — структурированный набор товаров с навигацией, поиском и карточками.

**Артикул** — обозначение изделия, по которому покупатель может искать товар; не обязательно уникальный идентификатор записи в БД.

**Вариант изделия** — исполнение товара (например, ремонтный размер), которое может иметь общий базовый артикул с другими вариантами.

**Заявка / обращение** — сообщение покупателя с вопросом о цене, наличии, изготовлении или условиях поставки.

**Квалифицированная заявка** — обращение, соответствующее критериям, которые ещё предстоит согласовать с компанией.

**MVP** — минимально достаточная первая версия для проверки основной ценности продукта.

**P0 / P1 / P2** — приоритеты функциональности: обязательный первый релиз / следующий этап / отложенное развитие.

**SEO** — поисковая оптимизация, направленная на удобную индексацию и релевантность страниц.

**SSG / SSR** — предварительная генерация HTML / серверный рендеринг HTML. Способ реализации пока не утверждён.

**ADR** — документ о значимом архитектурном решении, альтернативах и последствиях.

**Definition of Done** — набор проверок, после которых задача считается завершённой.
