## Статусы документов

- **Draft** — содержимое может измениться; не считается утверждённым требованием целиком.
- **In review** — обсуждается / проверяется ответственным.
- **Approved** — принято и может служить основанием для реализации.
- **Superseded** — заменено новой версией; сохраняется для истории.

## Как фиксируем новое решение

1. Уточняем, относится ли утверждение к подтверждённым фактам, предположениям или открытым вопросам.
2. Обновляем соответствующий документ.
3. При значимом техническом выборе записываем ADR.
4. Создаём или обновляем задачу в бэклоге.
5. Сохраняем изменения через Git-коммит / PR.
