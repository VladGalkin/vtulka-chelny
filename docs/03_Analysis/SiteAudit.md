# Аудит существующего сайта

**Задача:** VT-002. **Статус:** карта публичных страниц собрана. **Дата:** 2026-11-23.

Объект — [vtulka-chelny.ru](https://vtulka-chelny.ru/). Действующий сайт служит источником сведений о компании и продукции. Структуру нового каталога определяем по актуальному ассортименту и требованиям проекта. Проверка `robots.txt` и прохождение сценария покупателя исключены из согласованного объёма.

## Карта публичных страниц

Карта собрана из внутренних ссылок в HTML главной страницы, меню и доступных разделов. HTTP-статусы относятся к первичной проверке. Запросы следовали за перенаправлениями, конечные адреса совпали с адресами в таблице.

| Адрес | HTTP | Подтверждённое наблюдение | Как использовать |
|---|---:|---|---|
| [Главная](https://vtulka-chelny.ru/) | 200 | Заголовок «О компании». `canonical` указывает на `/about`. | Учесть оба адреса при планировании миграции. |
| [О компании](https://vtulka-chelny.ru/about) | 200 | Сюда ведёт пункт меню «Главная». Есть ссылка на прайс-лист. `canonical` указывает на этот же адрес. | Взять описание компании за исходный материал для сверки. |
| [Запчасти](https://vtulka-chelny.ru/produkt) | 200 | Раздел «Бронзовые втулки, втулки латунные». `canonical` указывает на этот же адрес. | Использовать названия и группировку продукции при сверке ассортимента. |
| [Прайс-лист](https://vtulka-chelny.ru/price) | 200 | В HTML 28 строк таблицы и пометка «Цены договорные». `canonical` указывает на этот же адрес. | Сверить позиции и артикулы с актуальным ассортиментом. Число строк таблицы само по себе не определяет число изделий. |
| [Контакты](https://vtulka-chelny.ru/kontact) | 200 | Сюда ведёт пункт меню «Контакты». `canonical` указывает на этот же адрес. Один повторный запрос завершился по тайм-ауту. | Сверить контактные сведения с компанией. |

## Другие наблюдения

- Среди внутренних ссылок проверенных страниц отдельные карточки изделий и подразделы каталога не обнаружены. Покрытие карты ограничено публичной навигацией.
- В HTML главной есть ссылки на Telegram и WhatsApp. Наличие ссылок подтверждено. Доставка обращений через эти каналы отдельно не проверялась.
- Запрос к [`/sitemap.xml`](https://vtulka-chelny.ru/sitemap.xml) вернул HTTP 404. Наличие карты сайта по другому адресу не установлено.
- Достоверной исторической статистики посещений и конверсии в проектной документации пока нет. Индексация, поисковый трафик и результативность сайта в рамках этой проверки не оценивались.

## Что требует подтверждения

- `/` и `/about` могут представлять один материал. Одинаковый заголовок и `canonical` главной дают основание сравнить страницы перед выбором адреса и правил перенаправления.
- Дополнение от 26.11.2026. В публичном прайсе подтверждены четыре исполнения под номером 5320-2918074. Актуальный ассортимент и значения размеров предстоит сверить с директором. [Проверка в VT-004](CompetitorsAndSearchDemand.md)
- У компании уточнить актуальные характеристики, ассортимент, изготовление на заказ, условия поставки, контакты и разрешения на использование материалов. Вопросы собраны в [OpenQuestions.md](../02_Requirements/OpenQuestions.md).

Публичные страницы проверены через `curl`. Для карты использовались HTTP-статусы, конечные адреса, заголовки, внутренние ссылки и `canonical` в полученном HTML.
