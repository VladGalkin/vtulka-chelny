# Целевая аудитория

**Статус:** Draft. Сегменты названы в анализе; конкретные потребности — гипотезы для проверки.

Все четыре группы **примерно равнозначны по бизнес-приоритету** на старте. Сегменты описаны в [Vision v0.2](../01_Project/Vision.md#4-целевая-аудитория). Задачи посетителей и важная для них информация в таблице — рабочие гипотезы.

| Сегмент | Возможная задача посетителя | Важная информация на сайте |
|---|---|---|
| Автосервисы и ремонтные предприятия | Найти деталь по артикулу/применяемости и быстро уточнить поставку | Поиск, размеры, марки техники, связь |
| Транспортные компании и автопарки | Подобрать изделия для обслуживания автопарка, запросить партию | Номенклатура, условия поставки, запрос цены |
| Магазины автозапчастей и оптовые покупатели | Найти позиции для снабжения или перепродажи | Артикулы, ассортимент, оптовые условия — если подтверждены |
| Производственные предприятия и заказчики изделий по чертежам | Найти готовое изделие или запросить изготовление по параметрам или чертежам | Ассортимент, возможности изготовления, контакт, формат запроса |

Снабженец, механик и специалист по ремонту — возможные роли пользователей внутри этих групп.

## Универсальные пользовательские задачи (гипотезы)

1. «У меня есть артикул — хочу быстро найти нужную деталь».
2. «Я знаю тип детали, но уточняю применяемость и размер».
3. «Мне нужна цена и условия поставки без сложной регистрации».
4. «Мне нужно изготовление по чертежу — хочу узнать, возможно ли это».

## Что проверить позднее

- Наиболее частые запросы и возражения покупателей.
- Какие параметры изделий определяют покупку.
- Предпочтительные способы общения.
- Точные географические приоритеты.
- Различия между сегментами, которые оправдывают отдельные посадочные страницы.
