## Какие запросы проверить

Примеры составлены по прайсу, страницам поставщиков и [сценариям VT-003](TargetAudience.md). Они показывают разные намерения покупателя. Региональные измерения приведены ниже.

| Намерение | Примеры формулировок | Подходящая страница и действие |
|---|---|---|
| Найти известную деталь | 5320-2918074; 53202918074; втулка 6520-3001016 | Карточка изделия. Сверить артикул, увидеть исполнения, уточнить цену у директора. |
| Выбрать исполнение | втулка балансира бронза Р1 87,5; втулка балансира 5320 ремонтная | Та же карточка с таблицей вариантов. При обращении покупатель может назвать нужный вариант. |
| Найти по названию и технике | втулка шкворня КамАЗ 6520; втулка ушка передней рессоры 5320 | Карточка или раздел каталога, если по запросу действительно подходят несколько изделий. |
| Найти поставщика поблизости | бронзовые втулки Набережные Челны; втулка балансира купить Набережные Челны | Каталог и контакты с фактическими условиями получения. Территорию поставок уточнить по OQ-007. |
| Найти изготовителя | изготовление втулок по чертежам Набережные Челны | Страница услуги после подтверждения её содержания. Указать, как обсудить заказ с директором. |

## Проверка источников 26 ноября 2026 г.

Прайс компании, страницы «Склад ТФК», «КамаЦентр» и НЧЗТА ответили HTTP 200. В прайсе повторно сверены строки по 5320-2918074. У «КамаЦентра» подтверждены три способа записи номера и ремонтное исполнение Р1 87,5. У НЧЗТА подтверждён приём заказов по чертежам и образцам. Для КАМА-RIK использовано индексированное описание карточки: при повторном прямом запросе сайт не ответил за восемь секунд.

## Приоритет для каталога

Первую карточку стоит проработать для втулки балансира 5320-2918074. Покупатели ищут деталь и по названию с маркой техники, и по артикулу. В заголовке карточки уместны оба признака. Поиск внутри каталога стоит проверить на номере с дефисом и без него. В карточке полезно показать материал и ремонтные исполнения, которые подтвердит директор.

За месяц запрос с названием города «бронзовые втулки Набережные Челны» дал пять обращений к поиску. Этого среза мало для решения об отдельных городских страницах. Для изготовления по чертежам виден общероссийский спрос. Перед подготовкой страницы услуги остаётся уточнить возможности предприятия и географию поставок. Частотность характеризует интерес к теме, включая информационные запросы. Прогноз числа клиентов требует данных о переходах и обращениях.

## Выводы для следующих задач

- **VT-005, требования.** Проверить на реальном артикуле, сможет ли покупатель найти изделие при вводе номера с дефисом и без него, выбрать исполнение и сообщить его директору при запросе цены.
- **VT-009, страницы и URL.** Для первого прототипа рассмотреть одну постоянную страницу изделия с вариантами. Отдельные страницы вариантов или услуг обосновывать различиями в содержании и данными о спросе.
- **Проверка результата после запуска.** Отдельно проверять доступность карточек для индексации, показы по целевым фразам и обращения по изделиям. Для оценки последнего показателя согласовать с директором способ учёта. [Открытые вопросы проекта](../02_Requirements/OpenQuestions.md)
