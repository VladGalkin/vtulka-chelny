# VT-005. Функциональные требования

**Статус** — Approved. Основание — [Vision v0.2](../01_Project/Vision.md), [границы MVP](MVPScope.md) и исследования VT-002–004. Владелец проекта отдельно утвердил поиск по названию в P0.

## P0 — первая версия

| Возможность | Что должен уметь посетитель |
|---|---|
| Главная | Понять, что предлагает компания, и перейти в каталог, к изготовлению на заказ или к контактам. |
| Каталог | Просматривать группы изделий и открывать карточки позиций. |
| Поиск по артикулу и названию | Найти изделие по известному артикулу или названию и открыть карточку. Если совпадений нет, получить понятный путь к каталогу или контактам. |
| Карточка | Открыть изделие по постоянному адресу, сверить название, артикул и подтверждённые характеристики. Если под одним артикулом есть несколько подтверждённых исполнений, различить их до обращения. |
| Запрос цены | Обратиться по конкретному изделию и сообщить выбранное исполнение, если их несколько. Перед выпуском отправить тестовый запрос по согласованному каналу и подтвердить у ответственного, что обращение дошло с данными об изделии. |
| Изготовление на заказ | Ознакомиться с подтверждёнными возможностями компании, узнать, какие сведения нужны для первичной оценки, и как обратиться по заказу. |
| Контакты | Найти актуальные способы связи с компанией и воспользоваться ими. |

## Что подтвердить перед реализацией

- Для проверки поиска по артикулу взять `5320-2918074` и `53202918074`. В публичном прайсе найдены четыре исполнения под этим артикулом. Актуальность исполнений и расшифровку размеров необходимо подтвердить перед публикацией. [VT-002](../03_Analysis/SiteAudit.md) · [VT-004](../03_Analysis/CompetitorsAndSearchDemand.md)
- По [VT-003](../03_Analysis/TargetAudience.md) покупатели сейчас связываются с директором. Получателя обращений нового сайта, канал, способ проверки доставки и поля запроса согласовать по OQ-001–003. Сведения для карточек, контакты и услугу подтвердить по OQ-005–006, OQ-009 и OQ-016. ## P1 — возможные расширения

- Административная панель. Необходимость к запуску зависит от того, кто и как часто обновляет каталог (OQ-012).
- Запрос цены по нескольким позициям одним обращением.
- Загрузка чертежей или других файлов. Потребность и безопасный способ работы с файлами уточняются по OQ-008 и OQ-011.
