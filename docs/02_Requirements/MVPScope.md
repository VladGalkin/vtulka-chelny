# Границы MVP и приоритеты

**Статус:** Draft (предварительная декомпозиция). **Дата:** 2026-11-23.

Источник границ первой версии — [Vision v0.2](../01_Project/Vision.md#7-границы-первой-версии-mvp).

## P0 — обязательно для первой работающей версии

| Код | Возможность | Минимальный проверяемый результат |
|---|---|---|
| MVP-01 | Публичные SEO-страницы | Страницы компании и основных направлений деятельности, а также карточки изделий доступны по постоянным URL и могут индексироваться |
| MVP-02 | Каталог | Посетитель может просматривать товары и группы изделий |
| MVP-03 | Поиск по артикулу | Пользователь находит изделие по известному артикулу |
| MVP-04 | Запрос цены | Посетитель может запросить цену по конкретному изделию |
| MVP-05 | Контакты | Посетитель быстро находит способы связи |
| MVP-06 | Передача обращения | Проверено, что ответственное лицо получает обращение по согласованному каналу |
| MVP-07 | Адаптивный интерфейс | Основные сценарии доступны на компьютере и мобильном телефоне |
| MVP-08 | Базовая аналитика | Отслеживаются основные действия, включая успешную отправку формы, если она используется. События аналитики учитываются отдельно от подтверждённых целевых обращений |
| MVP-09 | Изготовление на заказ | После подтверждения актуальных услуг и материалов компании посетителю доступны сведения об изготовлении и способ обращения |

**Примечание:** детали формы, уведомлений и обработки обращений не согласованы. Реализация MVP-04/06 требует уточнений.

## P1 — после базового сценария, требует уточнения

- Административная панель для управления каталогом и/или заявками.
- Запрос стоимости нескольких позиций за одно обращение.
- Специализированная форма с возможностью прикрепить чертёж или другой документ и проверкой безопасности хранения вложений.
- Расширенное управление и история обращений.

Необходимость административной панели к первому запуску и состав P1 уточняются отдельно.

## P2 — за рамками текущего релиза

- Личный кабинет покупателя.
- Онлайн-оплата и полноценное оформление заказа как в интернет-магазине.
- Сложные интеграции с внутренними системами — только при отдельном бизнес-запросе.

## Критерий релизной готовности P0

Посетитель может найти изделие, открыть карточку с проверенными сведениями и запросить цену. Если услуга и материалы подтверждены, посетитель может также узнать, как обратиться по изготовлению на заказ. Проверены получение обращения ответственным, основные действия на компьютере и мобильном телефоне, базовые SEO и аналитика.

До выпуска проверены базовые меры безопасности и корректная обработка данных обращений. Детальные критерии конкретизируются в требованиях и тест-плане.
