# Архитектура — рабочий раздел

Пока архитектура **не утверждена**. Предварительно рассматривается Angular с SEO-совместимым рендерингом, NestJS, Prisma, PostgreSQL и Docker Compose.

Позднее здесь появятся:

- `Architecture.md` — компоненты и их взаимодействие;
- `ADR-0001-...md` — значимые технические решения, альтернативы и последствия;
- `ApiDesign.md` — контракт API;
- материалы по безопасности и работе с файлами.

Архитектуру следует выбрать после уточнения требований к каталогу, администрированию и передаче заявок.
