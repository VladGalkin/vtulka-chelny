# vtulka-chelny — новый сайт-каталог

> **Статус:** проектирование и сбор требований. Программная реализация ещё не начата.

Проект нового коммерческого B2B-сайта-каталога для [vtulka-chelny.ru](https://vtulka-chelny.ru/). Основная бизнес-цель — привлекать новых потенциальных B2B-покупателей из интернета и получать больше целевых обращений по приобретению или изготовлению продукции. Существующий сайт продолжает работать до контролируемой миграции.

## Принцип продукта

Сайт помогает найти нужное изделие, уточнить его характеристики и **запросить цену / связаться с компанией**. Онлайн-оплата и полноценная корзина не относятся к первому релизу.

## Предварительный технологический ориентир

Angular + SSR/SSG, TypeScript, NestJS, Prisma, PostgreSQL, Docker Compose, GitHub Actions. **Это не утверждённая архитектура:** окончательное решение принимается после требований и ADR. Текущая версия репозитория содержит только документацию.

## Рабочий процесс

`Backlog → Planned → In Progress → Review → Done`. Каждая значимая задача обсуждается, фиксируется в документации, разрабатывается в отдельной ветке и проходит проверку перед слиянием.

## Безопасность и публикация

Репозиторий публичный. Пароли, `.env` и ключи хранятся вне Git. Данные клиентов, чертежи заказчиков и внутренние материалы публикуются только при наличии надлежащего разрешения.
